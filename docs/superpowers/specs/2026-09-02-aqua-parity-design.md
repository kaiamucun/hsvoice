# HS Voice 1.7.0 — Aqua Voice から取り入れる設定・機能（設計）

日付: 2026-09-02
対象: macOS版 HS Voice（Sources/HSVoice）

## 目的

Aqua Voice 0.19.8 の設定画面と実機比較し、社内配布のオンデバイス音声入力として
価値が高く、ローカル処理の方針を崩さない範囲で、使いやすさと機能を取り込む。
クラウド前提の要素（アカウント、ネットワーク遅延、使用量カード）は対象外。

## 取り込む項目

1. 辞書の実効化と置換機能
   - 辞書エントリ = 正しい表記 + 読み／誤認識例（カンマ区切り、任意）。
   - 認識後テキストに対して「誤認識例 → 正しい表記」を置換。高精度エンジン
     （SpeechAnalyzer）でも効く。従来エンジンでは表記を contextualStrings にも渡す。
     AI整形が有効な場合は表記一覧をモデルへのヒントにも渡す。
   - 置換ルール = トリガー句 → 置換テキスト（メールアドレス、URL、定型文）。
   - 適用順: TextPostProcessor.process → 辞書 → 置換 → AI整形。
   - 上限: 辞書 500、置換 200。旧「customVocabulary」（1行1語）は初回起動時に
     辞書エントリへ移行。
2. マイク選択とテスト
   - CoreAudio で入力デバイスを列挙し、UID で保存。「システムのデフォルト」が既定。
   - 両エンジンの AVAudioEngine 起動前に inputNode の CurrentDevice を設定。
     選択デバイスが見つからない場合はデフォルトへ。
   - 「テスト」: 数秒間レベルメーターを表示する独立プローブ。
3. 起動方式「自動」
   - 短く押す → ハンズフリー開始（次の押下で停止）。長押し（0.35秒以上）→ 押している間だけ。
   - 既存の「押している間」「押すたびに開始・停止」は維持。既定値は変更しない。
4. AI整形へのカスタム指示
   - 自由記述をモデルの instructions の末尾に「追加指示」として付加。
5. 設定画面の再構成
   - サイドバー（NavigationSplitView）: 一般 / ショートカット / 音声認識 / 辞書 / 置換 /
     AI整形 / 履歴とプライバシー / 権限 / サポート。
   - 各項目の直下に1行説明。ページ上部にタイトルと副題。
   - 一般ページ上部に「fn を押しながら話す」ヒントカード。
   - ショートカットページに 有効化 / 再入力 / キャンセル(esc) / 55秒制限 を一覧表示。
   - 「デフォルトにリセット」を一般・ショートカットに用意。
   - ウインドウ既定サイズ 880×620。

## テスト

- TextReplacer: 辞書置換（最長一致、大小文字、語境界）、置換ルール、順序。
- ActivationPolicy: hold / toggle / auto の押下・解放判定。
- SettingsStore: 新設定の永続化、旧辞書の移行。
- 実機: 各ページのスクリーンショット確認、辞書と置換の実入力確認。
