HSVoice-Installer.pkg / 960 KB

インストール方法 1. 上のボタンから pkg をダウンロード
2. ダウンロードした pkg をダブルクリックしてインストール
3. 「アプリケーション」から HS Voice を起動
※ 開けない場合: システム設定 → プライバシーとセキュリティ →「このまま開く」
プライバシーについて 話した言葉が外部に送信されたり、どこかで悪用されることはありません。
音声や入力した内容は、基本的にお使いのパソコンの中にしか保存されません。
